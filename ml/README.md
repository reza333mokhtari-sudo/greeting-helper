# AI Assistance ML System

This directory contains the machine learning components for the Dungeon Scrawl Clone AI Assistant.

## Objectives
- Intent classification for user queries.
- RAG (Retrieval-Augmented Generation) quality evaluation.
- Competition-grade performance metrics.

## Components
- `train_intent.py`: Training script for intent classifier.
- `evaluate_assistant.py`: Evaluation suite for the assistant.
- `gold_dataset.json`: High-quality labeled dataset for training and eval.
