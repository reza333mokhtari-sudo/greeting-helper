# Troubleshooting

## Object won’t place
- Confirm library item loaded
- Click canvas after selecting item
- Check if a modal is open and blocking input

## Minimap wrong position
- Reset view
- Resize window once
- Toggle minimap visibility

## Camera fights tools
- Disable Camera mode
- Use View Cube only for orientation
- Ensure tool drag is active on canvas, not cube

## Popup won’t close
- Press Escape
- Click X
- Click backdrop if enabled
