# Quick Start

## 1. Open your map
Open the editor and wait for the canvas to load.

## 2. Move around
- Pan with the configured mouse/touch control
- Zoom with the wheel or trackpad

## 3. Place your first object
1. Click **3D**
2. Choose an object
3. Click/drag onto the map

## 4. Edit safely
- Move the object
- Use **Undo** if needed

## 5. Save
Save your map before leaving.

> **Tip**: Keep the viewport unchanged while adding objects from the 3D library.
